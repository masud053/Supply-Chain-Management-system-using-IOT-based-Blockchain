# Blockchain-Based Supply Chain Management System (Solidity | Ethereum)

## Overview
A **fully decentralized Supply Chain Management System** implemented using **Solidity** on the **Ethereum blockchain**.  
The project ensures **transparency, immutability, and security** in supply chain transactions by representing each stakeholder and product transfer as blockchain-verified smart contract interactions.

It provides end-to-end product traceability — from **Raw Material Supplier → Manufacturer → Warehouse → Retailer → Pharmacist → End User** — using decentralized logic and Ether-based payment validation.

## Features
- **Smart Contract Ownership Control**  
- **Decentralized Product Tracking**  
- **Role-Based Access for Stakeholders**  
- **Verified Ether Transactions**  
- **Immutable State Management (Purchase → Confirm → Deliver)**  
- **Event Logging for Transparency (Transfer & Ownership Change)**  
- **Secure Multi-Step Workflow (Raw → Manufacturer → End User)**
